# ПБиОТ 1.2 RC3 — универсальный выбор и тренировки

Это **предварительный выпуск Android для внутренней проверки**, не публикация в RuStore. Основная ветка `main` не изменяется.

**APK:** `PBiOT_Android_1.2_RC3_signed.apk`, пакет `ru.rpomng.pbiot`, versionCode `102`, Android 8.0+. SHA-256: `bffe6f5a2ad21f50732b0a4edfafc540b3174906a21a305566589e1263b7cb16`. Подпись релиза проверена.

Новое:
- единый каталог **118 программ** в пяти направлениях, поиск по области/группе/названию/билету;
- бесплатные вопросы из **выбранной** программы с общим лимитом **100 на направление**;
- пошаговая ознакомительная тренировка с выбором ответа, немедленной **предварительной** отметкой источника, переходом между вопросами и итогом без ложной нормативной оценки;
- поиск по оплаченным материалам в рамках действующих прав, с проверкой на сервере;
- сохранены серверная ЮKassa, срок доступа, защита заказа и восстановление покупки.

**Ограничения:** группы работ на высоте ещё нельзя надёжно выделить из имеющейся базы. Учебные отметки ответов не подтверждены действующими НПА. Не использовать как официальную аттестацию и не рассчитывать на телефон на экзамене, где он запрещён. Полный банк и ключ ЮKassa в APK отсутствуют. Для работы тематического демо и оплаченного поиска нужен интернет.

**Настоящие платежи:** включён рабочий магазин ЮKassa на Timeweb; не проводите пробную покупку без осознанного согласия на реальное списание. Эта сборка тестировалась без создания платежа. Ссылку на скачивание можно использовать только после успешной проверки GitHub Actions SHA-256, подписанного APK и обязательных файлов.

Исходники для внутренней сборки находятся на авторизованном Mac в проекте `Документы/Мобильное приложение`. Файлы в `pbiot-v120-preview/base64/` — только транспорт подписанного APK в 15 частях. Секреты и полная база не публикуются.
