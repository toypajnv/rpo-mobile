# ПБиОТ Android 1.1 RC2 — проверка рабочей оплаты

Это **отдельная тестовая ветка**. Основная ветка проекта `rpo-mobile` не изменялась.

**Назначение:** установленный Android APK для личного контрольного платежа через рабочий магазин ЮKassa (ShopID 1527848). Файл сборки будет прикреплён к предварительному [релизу `pbiot-v1.1.0-rc2-test`](https://github.com/toypajnv/rpo-mobile/releases/tag/pbiot-v1.1.0-rc2-test).

**Важно:** пробная реальная оплата списывает настоящие деньги. Первый платёж инициируется пользователем самостоятельно. Платёж доступен только через официальную форму ЮKassa, подтверждение и выдача доступа выполняются на сервере Timeweb. Сборка не содержит секретного ключа API.

- APK: `PBiOT_Android_1.1_RC2_signed.apk`, версия 101
- Package ID: `ru.rpomng.pbiot`
- SHA-256: `0a1487e10e89cc72dfcdb6718531c7541f1c7dd4a46a4404d6bed4c30f5eacdb`
- Размер: 4 999 695 байт
- Бесплатный пакет: 500 учебных вопросов (100 × 5 модулей)
- Остальные вопросы: запрашиваются у сервера при подтверждённых правах
- Оплачиваемая услуга: учебные материалы, **не государственная аттестация**, правильность ответов не подтверждена официально
- Автоматических подписок и автосписаний нет

В папке `base64/` лежит 15 частей **только подписанного APK**, закодированных в Base64, без закрытого ключа и серверной базы. GitHub Actions собирает исходный APK из этих частей, проверяет SHA-256 и публикует его как актив `prerelease`. Не размещайте в репозитории секреты ЮKassa.

**Перед оплатой:** проверьте, что на экране приложения указана ожидаемая цена, а в браузере открыта HTTPS-страница ЮKassa. Успешная оплата считается подтверждённой только после нажатия «Проверить оплату на сервере» и получения доступа. Для получения чека НПД обратитесь к продавцу: он оформляется в «Мой налог».

Публикация в RuStore пока не выполнена.

Проверка именно загруженного APK: подпись APK v2 подтверждена, шесть экранных проверок Android 15 успешно пройдены при активном сервере ЮKassa; реальных списаний не выполнялось.
