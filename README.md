# РПО Мобайл + РПО Сервер (MVP)

Отдельная клиент-серверная система для передачи этапов работ повышенной опасности. Исходная локальная РПО-система не изменяется.

## Архитектура

- **Android** — Kotlin + Jetpack Compose, без логина в релизе 1.
- **РПО Сервер** — FastAPI + SQLAlchemy + PostgreSQL (SQLite для локального запуска).
- **Веб-панель оператора** — серверный HTML/CSS/JS, вход по логину/паролю.
- **Выгрузка** — оператор выбирает период и email, сервер формирует XLSX + JSON и отправляет вручную по кнопке.

## Этапы и соответствие локальной базе

| Ключ | Этап |
|---|---|
| AT | Начало подготовки |
| AU | Окончание подготовки |
| AV | Передача ОП к ОБПР |
| AX | Допуск со стороны допускающего |
| AY | Фактическое начало работ |
| AZ | Остановка работ |
| BB | Причина остановки (создаётся вместе с AZ) |
| BA | Возобновление работ |
| BC | Фактическое завершение РПО |
| BD | Выполнение мероприятий по завершению |
| BE | Продление РПО |
| BF | Выполнение мероприятий по передаче объекта |
| BG | Закрытие ЭНД |
| BH | Передача площадки эксплуатирующей организации |

## Быстрый локальный запуск сервера

```bash
cd server
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
cp ../.env.example .env
uvicorn app.main:app --reload --port 8000
```

Открыть: `http://localhost:8000/login`

По умолчанию из `.env.example`: `admin / ChangeMe123!` — обязательно заменить перед размещением в интернете.

### Email

По умолчанию `MAIL_MODE=file`: сервер формирует письмо как `.eml` в `server/data/outbox/`, поэтому весь сценарий можно проверить без почтового сервера.

Для реальной отправки выставить:

```env
MAIL_MODE=smtp
SMTP_HOST=smtp.example.ru
SMTP_PORT=587
SMTP_USERNAME=user@example.ru
SMTP_PASSWORD=secret
SMTP_FROM=user@example.ru
SMTP_STARTTLS=true
```

## Docker / VPS

```bash
docker compose up -d --build
```

Перед VPS нужно задать секреты в `.env`: `SECRET_KEY`, пароль оператора, PostgreSQL и SMTP.

## Android

Проект находится в `android/`. В `app/build.gradle.kts` задан `BuildConfig.SERVER_URL`.
Для эмулятора Android при локальном сервере используется `http://10.0.2.2:8000/`.
Перед релизной сборкой заменить URL на HTTPS-адрес VPS.

## Логика релиза 1

1. Работник без логина вводит ФИО (оно запоминается на устройстве).
2. Номер наряда-допуска вводится вручную.
3. Выбирается этап.
4. Дата/время вводятся вручную либо кнопкой **Сейчас**.
5. Приложение проверяет обязательные поля и очевидные ошибки.
6. Сервер повторно валидирует данные и последовательность ключевых этапов.
7. Оператор видит поступления в веб-панели.
8. Оператор выбирает период и вручную формирует/отправляет выгрузку.
9. События после успешной отправки помечаются как выгруженные, но не удаляются.
