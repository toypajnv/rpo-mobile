# Мониторинг вакансий ПБ на rpo-mng.ru

Адрес: https://rpo-mng.ru/vacancies

Поиск каждые 60 минут на HeadHunter: охрана труда, промышленная, производственная,
пожарная безопасность, ПБОТОС, HSE, экология, техносферная безопасность, ГО и ЧС,
безопасность дорожного движения. Регионы: Тюмень и Нижневартовск.
Компании: СИБУР, Транснефть, НОВАТЭК, Газпром, Роснефть и узнаваемые
дочерние предприятия.

## Доступ

Страница защищена существующей авторизацией панели РПО через /login;
пароли не вшиваются в код. В панели есть ссылка «Вакансии ПБ».
Администратор может создать учётную запись «Руководитель» для просмотра.
Внимание: это общий механизм авторизации РПО, поэтому аккаунт с ролью
«Руководитель» также имеет доступ к существующей панели РПО.
Для отдельного контура доступа потребуется отдельная роль.

## Настройка источника

Используется официальный API HH: https://api.hh.ru/
Публикации только на корпоративных сайтах компаний, отсутствующие на HH,
пока не охвачены.

1. Зарегистрируйте приложение на https://dev.hh.ru/.
2. Получите OAuth access_token приложения (client_credentials) в соответствии
   с документацией https://api.hh.ru/openapi/redoc.
3. На сервере в /opt/rpo/.env задайте значения (НЕ храните их в GitHub):
   HH_API_TOKEN=<токен_приложения>
   HH_USER_AGENT=RPOVacancies/1.0 (реальный-контакт@example.org)
4. В каталоге /opt/rpo запустите:
   sudo docker compose up -d --build vacancies-worker
5. Посмотрите журнал:
   sudo docker compose logs --tail=50 vacancies-worker

Без токена HH может возвращать капчу и отказ 403: мониторинг покажет
ошибку источника. Капча и ограничения сервиса не обходятся.

## Фоновое обновление

Контейнер vacancies-worker опрашивает HH сразу после запуска, далее каждый час.
Сведения сохраняются в отдельные таблицы PostgreSQL: tracked_vacancies
и vacancy_scans. Уникальный ключ source + source_id предотвращает дубли.
При полной успешной проверке не найденные вновь вакансии помечаются
неактуальными; при ошибке API старые данные остаются без изменений.
История запусков и ошибок доступна на странице. Данные РПО не затрагиваются.

## Ограничения

- Только объявления, размещённые на HH, а не все корпоративные порталы.
- При отзыве токена требуется получить новый токен.
- Закрывшаяся вакансия может оставаться видимой до следующей проверки.
- Для просмотра требуется активная сессия пользователя РПО.
