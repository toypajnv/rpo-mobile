# Мониторинг вакансий по промышленной / производственной безопасности

Сайт: https://rpo-mng.ru/vacancies
Отдельный вход: https://rpo-mng.ru/vacancies/login

## Авторизация

Система использует отдельную учётную запись «admin» и пользовательский
пароль, установленный при разработке раздела. Он сохранён только в виде
солёного Argon2id-хеша. Доступ к РПО от этого пароля не появляется.
Для смены учётных данных задайте в /opt/rpo/.env:

    VACANCY_ADMIN_USERNAME=admin
    VACANCY_ADMIN_PASSWORD_HASH=<Argon2id_хеш_нового_пароля>

Хеш можно получить локально из контейнера:

    sudo docker compose exec -T server python -c "from app.security import hash_password; import getpass; print(hash_password(getpass.getpass()))"

Не сохраняйте исходный пароль в GitHub, журналах или файлах в общих папках.
При доступе через отдельный вход сессия действует 8 часов.
После пяти ошибочных попыток предусмотрена временная блокировка по IP.

## Источники (каждый час)

- HeadHunter: официальный API (рекомендуется OAuth HH_API_TOKEN).
- Официальный карьерный портал СИБУР: https://career.sibur.ru/vacancies/
- Транснефть-Сибирь: https://siberia.transneft.ru/
- НОВАТЭК: https://www.novatek.ru/ru/about/career/jobs/
- Газпром: https://www.gazpromvacancy.ru/vacancies/
- Роснефть: https://www.rosneft.ru/about/career/
- Авито Работа: общедоступные страницы раздела «Вакансии» в двух городах.

Сборщик читает HTML только при разрешении robots.txt. Не пытается обходить
капчи, Cloudflare, QRATOR, логин или HTTP 403. Карточка сохраняется только
если распознаны город, должность с целевыми ключевыми словами и работодатель.
Сторонние объявления на Авито без подтверждаемого названия компании
не включаются в мониторинг. Некоторые корпоративные страницы не содержат
машиночитаемых вакансий или закрывают роботам доступ; в этих случаях
источник отмечается как недоступный и не создаёт ложных результатов.

Сведения из разных источников сохраняются в отдельных таблицах
tracked_vacancies и vacancy_scans. Отсутствующие после успешного опроса
объявления архивируются только в соответствующем источнике. Ошибка одного
сайта не удаляет вакансии из другого. В интерфейсе есть фильтр «Источник».

Проверка на сервере:

    cd /opt/rpo
    sudo docker compose ps
    sudo docker compose logs --tail=100 vacancies-worker

Обновление: каждый час; первая проверка происходит после запуска worker.
Для реального покрытия Авито лучше получить лицензированный доступ к API
или согласованный фид поиска. Публичный Avito API для работодателей обычно
предоставляет управление вакансиями своего аккаунта, а не глобальный поиск.
