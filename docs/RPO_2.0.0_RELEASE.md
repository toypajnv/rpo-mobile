# РПО 2.0.0 — глобальное обновление

## Основные изменения

- Операторское разрешение для каждого нового события этапа, кроме остановки работ (`AZ`).
- Повторная передача этапа создаёт новый запрос на разрешение.
- Мобильное приложение автоматически опрашивает сервер и показывает статусы «Ожидает разрешения оператора», «Работы можно проводить» и «Работы остановлены».
- Обязательный выбор структурного подразделения в новой версии Android: ЦДПН-1, ЦДПН-2, ЦДПН-3, ЦДПН-4, ЦППН-1, ЦППН-2, ЦСДиТГ, ЦСиР, ЦТОиРТ-1, ЦТОиРТ-2.
- Старые APK остаются совместимыми: сервер принимает события без структурного подразделения.
- Глобальный поиск и фильтр по подразделению во всех рабочих вкладках панели оператора.
- Аудит разрешений: событие, оператор и время подтверждения.
- Безопасное автоматическое расширение схемы существующей PostgreSQL.

## Контроль перед production

1. Quality Gate: backend regression tests — success.
2. Quality Gate: Android unit tests — success.
3. PR develop → main — повторная проверка success.
4. Production Smoke — сервер 0.5.0 / mobile 2.0.0.
5. GitHub Release `v2.0.0-test` содержит `rpo-mobile-2.0.0.apk`.
